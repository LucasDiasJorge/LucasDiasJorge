## 👋 About me

Full-stack developer with a backend-first focus. My projects span **C#/.NET and Java/Spring APIs**, **TypeScript/JavaScript interfaces with Vue**, and distributed services built around Kafka/RabbitMQ, REST/gRPC, and JWT/Keycloak authentication.

I also work close to hardware and protocols: **RFID reader integrations**, ESP32/ESP8266, MQTT, LoRa, Modbus, and low-level/concurrent programming in **C, C++ and Rust**. Other project areas include data processing, computer vision, local and on-device AI, and mobile/desktop apps with Flutter, Android, and Qt.

- 🧱 Backend-first, full-stack by choice — I take features from domain/API design through persistence, integrations, and UI.
- 🔌 I enjoy connecting software with hardware and external systems: reader workflows, event messaging, sockets, and embedded protocols.
- 🧪 I value maintainable architecture and testing, and use Docker, Linux, and deployment automation to run projects reliably.
